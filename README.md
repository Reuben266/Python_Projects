# 🐍 Python Projects Portfolio

Welcome to the **Python Projects Portfolio** repository! 🚀 This repository contains a curated collection of Python applications, ranging from core procedural scripts and file handling utilities to modular, object-oriented systems.

---

## 📋 Overview of Projects

### 1. 🏦 Object-Oriented Banking & Persistence System
* **Description:** A robust banking system implementing Object-Oriented Programming (OOP) principles alongside a modular file persistence layer.
* **Key Features:**
  * Support for Bank Accounts and Savings Accounts.
  * Inter-account money transfers, deposits, withdrawals, and loan management.
  * Transaction history logging and balance rule enforcement.
  * Standalone persistence module (`file_persistence.py`) using JSON for data storage and retrieval.
  * Comprehensive error handling for missing or corrupted data files (`JSONDecodeError`, `FileNotFoundError`).

### 2. 🧹 Automated Log & File Sanitizer
* **Description:** A security utility designed to inspect text log files and remove or mask sensitive information.
* **Key Features:**
  * Keyword and pattern matching for sensitive text.
  * Automated cleaning and log export.
  * Custom keyword filtering rules.

### 3. 📊 CSV Sales & Game Data Analyzer
* **Description:** A data analytics script for processing structured CSV datasets.
* **Key Features:**
  * Aggregation of total sales revenue and product sales statistics.
  * Top-performing item identification.
  * Automated summary report output.

### 4. 📇 JSON Contact Book Manager
* **Description:** A contact management tool leveraging JSON storage.
* **Key Features:**
  * Duplicate contact validation and rejection.
  * Persistent reading and writing to JSON files.
  * Interactive CLI menu interface.

### 5. 🧮 Matrix Multiplication Utility
* **Description:** A mathematical utility executing 2x2 matrix multiplication algorithms.
* **Key Features:**
  * Iterative calculations using optimized loop structures.
  * Clean numerical processing logic.

### 6. 🔢 Binary & Decimal Converter
* **Description:** A conversion tool for transforming positive integers into binary representations.
* **Key Features:**
  * Binary digit string validation.
  * Numerical conversion logic without relying on external libraries.

---

## 🛠️ Key Technical Highlights

* **Object-Oriented Programming:** Encapsulation, inheritance, and state isolation across multiple domain models.
* **Modular Persistence Architecture:** Clear separation of business logic from file I/O operations using standalone function modules.
* **Defensive Error Handling:** Granular exception handling protecting against empty files, missing paths, and invalid data formats.
* **Data Processing:** Handling structured data formats including JSON logs, CSV records, and matrix datasets.

1. **Clone the Repository:**
   Clone the repository to your local environment using Git.

2. **Run a Project:**
   Execute any project file using a Python 3 environment. For example, run `main.py` inside the banking system directory to launch the application interface.
